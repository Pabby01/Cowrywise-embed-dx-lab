Cowrywise Embed Quickstart: 0 to 1 in 5 Minutes

From initial SDK installation to creating accounts, completing Tier-1 BVN identity verification, funding wallets, and purchasing your first mutual fund units.

1. Prerequisites

Before integrating with Cowrywise Embed in production or sandbox:

  1. Developer Portal Account: Request early access at developers.cowrywise.com.
  2. Sandbox API Credentials: Obtain your client_id and client_secret from the partner dashboard.
  3. Node.js Environment: Node.js version 18.x or 20.x (LTS recommended).
🔒 Server-Side Security Rule: Your client_secret must never be exposed in frontend client-side bundles (React, Vue, mobile apps, or public Git repos). All calls to the Cowrywise Embed API must be made from your secure backend server.

2. Installation

Install the official Cowrywise Embed Node.js SDK from npm:

bash — npm install 
npm install @cowrywise/embed-node
# or using yarn
yarn add @cowrywise/embed-node

To experiment with our local type-safe mock engine without needing real sandbox credentials:

bash — clone starter lab 
git clone https://github.com/Pabby01/Cowrywise-embed-dx-lab.git
cd cowrywise-embed-dx-lab
npm install
npm run demo

3. Client Initialization

Configure the SDK client in your backend server using environment variables:

typescript — client.ts 
import Client from "@cowrywise/embed-node";

const cowrywise = new Client({
  client_id: process.env.COWRYWISE_CLIENT_ID!,
  client_secret: process.env.COWRYWISE_CLIENT_SECRET!,
  embed_api_base_url: process.env.NODE_ENV === "production"
    ? "https://embed.cowrywise.com/api/v1"
    : "https://sandbox.embed.cowrywise.com/api/v1"
});

4. The 4-Step Integration Journey

Step 1: Create Customer Investment Account

Every customer requires an investment account before assets or savings plans can be provisioned:

typescript — 1.create-account.ts 
const account = await cowrywise.accounts.createAccount({
  first_name: "Chidi",
  last_name: "Okonkwo",
  email: "chidi.okonkwo@example.com",
  phone_number: "+2348012345678",
  terms_of_use_accepted: true // Mandatory
});

console.log("Account created:", account.account_id);
// Status is "pending_verification"

Step 2: Verify Identity (Tier-1 BVN KYC)

Nigerian regulatory compliance mandates Bank Verification Number (BVN) validation. In the sandbox environment, use the standard test BVN 22222222281:

typescript — 2.verify-identity.ts 
const kyc = await cowrywise.accounts.updateIdentity(account.account_id, {
  identity_type: "bvn",
  identity_value: "22222222281" // Sandbox test BVN
});

console.log("KYC status:", kyc.is_verified); // true
// An investment wallet is automatically provisioned upon successful verification!

Step 3: Fetch Catalog & Invest in Mutual Funds

Query SEC-regulated mutual funds (Money Market, Fixed Income, Balanced, Eurobonds) and purchase units:

typescript — 3.invest-funds.ts 
// 1. Fetch available investment catalog
const assets = await cowrywise.assets.getAssets();
const moneyMarketFund = assets.find(a => a.category === "mutual_fund");

// 2. Fetch the user's investment wallet
const [wallet] = await cowrywise.wallets.getWallets(account.account_id);

// 3. Purchase mutual fund units from wallet balance
const investment = await cowrywise.assets.investInAsset({
  accountId: account.account_id,
  assetId: moneyMarketFund.asset_id,
  amount: 25_000 // In NGN
});

console.log(`Purchased ${investment.units} units. Txn: ${investment.transaction_id}`);

Step 4: Create a Disciplined Locked Savings Plan

For goal-based savings with guaranteed annual returns (minimum 3 months duration lock):

typescript — 4.locked-savings.ts 
const savingsPlan = await cowrywise.savings.createSavingsPlan({
  account_id: account.account_id,
  name: "December Vacation Fund",
  target_amount: 300_000,
  initial_deposit: 20_000,
  duration_months: 6,
  interest_enabled: true
});

console.log(`Plan active until ${savingsPlan.maturity_date}`);

5. Webhook Signature Verification

Cowrywise sends real-time webhooks for asynchronous events (e.g. wallet.funded, withdrawal.completed). Always verify incoming signatures using constant-time HMAC SHA-256:

typescript — webhook-verifier.ts 
import crypto from "node:crypto";

export function verifyWebhook(
  incomingSignature: string,
  clientId: string,
  clientSecret: string
): boolean {
  if (!incomingSignature || !clientId || !clientSecret) return false;

  const expectedHash = crypto
    .createHmac("sha256", clientSecret)
    .update(clientId)
    .digest("hex");

  const expectedBuffer = Buffer.from(expectedHash.toLowerCase(), "utf8");
  const incomingBuffer = Buffer.from(incomingSignature.trim().toLowerCase(), "utf8");

  if (expectedBuffer.length !== incomingBuffer.length) return false;
  return crypto.timingSafeEqual(expectedBuffer, incomingBuffer);
}
