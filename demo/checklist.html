Interactive Pre-Flight Validation Checklist

Check off each requirement as your engineering team validates it. Click any row to toggle its completion state:

1. Confirm Sandbox Access: Confirm current sandbox access and credential issuance process directly with official Cowrywise representatives.
2. Verify API Base URLs: Confirm official API base URL (https://embed.cowrywise.com/api/v1) and authentication contract from official documentation.
3. Validate SDK Version: Confirm official @cowrywise/embed-node package name, supported Node versions (v18/v20+), and latest release tag.
4. Isolate Sandbox Credentials: Obtain authorized sandbox credentials; never use credentials or secrets belonging to another organization.
5. Verify Happy Path: Verify at least one end-to-end happy-path request against the live Cowrywise sandbox (Account -> KYC -> Fund -> Purchase).
6. Verify Fault Handling: Verify documented error handling for low balances (CW_ERR_INSUFFICIENT_FUNDS) and invalid BVN checks.
7. Validate Schemas: Confirm all JSON request and response schemas, currency codes (NGN), and UUID identifiers.
8. Webhook Cryptography: Confirm constant-time HMAC SHA-256 signature verification and idempotency deduplication before processing financial events.
9. Audit & Telemetry Logging: Record date, SDK release version, runtime environment, and integration test logs in partner telemetry.
10. Scope Honesty: Clearly label any untested edge cases. Until all checks pass, treat integration as sandbox mock mode.
Honesty Notice: Until these checks are fully verified with live credentials issued by Cowrywise, your deployment should remain in sandbox mode with synthetic mock data.
