Troubleshooting Matrix & Error Catalog

Diagnose and resolve integration blockers quickly. Every error documented below includes its HTTP status code, root cause, code remediations, and a live sandbox simulator trigger.

CW_ERR_INVALID_BVN HTTP 400

Bank Verification Number Failed Validation

The submitted BVN does not exist, contains non-numeric characters, or fails Luhn-11 checksum validation against the national NIBSS switch.

Remediation: Validate that the BVN is exactly 11 digits using regex ^\d{11}$ before dispatching API requests. In the sandbox, only use the certified test BVN 22222222281.
CW_ERR_WITHDRAWAL_LOCKED HTTP 422

24-Hour Cooling-Off Rule Active

A redemption or withdrawal was attempted within 24 hours of purchasing mutual fund or treasury units. SEC regulations mandate this holding window to prevent chargeback and ACH float abuse.

Remediation: Check investment.cooling_off_expires_at before rendering the "Sell Units" button. Show a friendly countdown timer in your frontend UI until the window elapses.
CW_ERR_INVALID_WEBHOOK_SIGNATURE HTTP 401

Webhook HMAC-SHA256 Mismatch

The inbound signature header does not match the computed hash of the raw request payload. This is almost always caused by body-parser middleware reordering JSON keys or stripping trailing whitespace.

Remediation: Compute HMAC over the raw UTF-8 request buffer before JSON parsing occurs. Verify using crypto.timingSafeEqual().
CW_ERR_INSUFFICIENT_FUNDS HTTP 400

Wallet Balance Lower than Order Total

The wallet does not have enough unencumbered funds to cover the subscription amount plus fund manager stamp duty (0.15%).

Remediation: Query GET /api/v1/wallets/:id to inspect available_balance before submitting order execution. Direct user to fund wallet via virtual account transfer.
CW_ERR_KYC_NAME_MISMATCH HTTP 422

Customer Name Does Not Match BVN Record

The first and last name provided during account creation differs significantly from the full legal name registered under the BVN at NIBSS.

Remediation: Ask the user to confirm their name as spelled on their official bank app or national NIN card, or initiate a Tier-2 document verification workflow with government ID upload.
CW_ERR_RATE_LIMIT_EXCEEDED HTTP 429

API Burst Rate Limit Exceeded

Your integration exceeded the limit of 120 requests/minute in the sandbox environment, or sent multiple concurrent duplicate calls without an idempotency key.

Remediation: Implement an exponential backoff retry mechanism (using HTTP headers Retry-After) and always attach unique Idempotency-Key headers to mutating POST requests.
