Anti-Fraud Protection

Asset Purchase & 24-Hour Cooling-Off Rule

SEC and CBN regulatory safeguards mandate a 24-hour mandatory holding lock on newly purchased investment units.

Test in Live Sandbox ↗
1
Select Mutual Fund

Partner queries approved SEC investment products (Money Market, Fixed Income, Eurobonds).

GET /api/v1/assets
2
Execute Unit Purchase

Units are purchased at today's Net Asset Value (NAV). Wallet balance deducted.

POST /api/v1/investments
3
24h Cooling-Off Active

Withdrawal is locked for 24 hours to prevent anti-money laundering and ACH bounce fraud.

Lock: CW_ERR_WITHDRAWAL_LOCKED
4
Daily Accrual & Liquidity

After 24 hours, interest accrues daily and units become fully redeemable into the wallet.

Settlement: T+1 Trading Day
Handling CW_ERR_WITHDRAWAL_LOCKED

If a partner initiates a liquidation before 24 hours elapsed, the API returns HTTP 422 with CW_ERR_WITHDRAWAL_LOCKED. UI clients should display a friendly countdown timer to inform users.

Security Architecture

HMAC-SHA256 Webhook Verification & Idempotency

Every webhook dispatched by Cowrywise Embed carries an HMAC signature header computed from your secret key and the raw payload.

Test in Live Sandbox ↗
1
Inbound Webhook

Cowrywise sends POST request with header X-Cowrywise-Signature.

Header: X-Cowrywise-Signature
2
Compute Expected HMAC

Partner server calculates HMAC-SHA256(raw_body, client_secret).

crypto.createHmac("sha256")
3
Constant-Time Compare

Compare hashes using crypto.timingSafeEqual to prevent timing attacks.

timingSafeEqual(computed, header)
4
Acknowledge HTTP 200

Return 200 within 4,000ms. Process long-running jobs asynchronously in background.

HTTP 200 OK (Quick ACK)
Raw Body Parsing Gotcha

In Express or NestJS, ensure your webhook endpoint uses raw body parsing (e.g. express.raw({type: 'application/json'})). Pre-parsed JSON objects will alter key order or whitespace and cause signature verification to fail!

// HMAC Verification Helper
import crypto from "crypto";

export function verifyWebhook(rawPayload, headerSignature, secret) {
  const hash = crypto
    .createHmac("sha256", secret)
    .update(rawPayload)
    .digest("hex");
    
  return crypto.timingSafeEqual(
    Buffer.from(hash),
    Buffer.from(headerSignature)
  );
}
