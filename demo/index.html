Developer Troubleshooting Matrix

Instant solutions for common integration roadblocks. Built by developers, for developers.

CW_ERR_INVALID_BVN (HTTP 400)

BVN Verification Rejected

BVN format is invalid or NIBSS biometric record does not match submitted name.

Fix: In Sandbox, always test with 22222222281. In Production, enforce an exact 11-digit regex before sending requests.
CW_ERR_INVALID_WEBHOOK_SIGNATURE (HTTP 401)

Webhook Signature Mismatch

Comparing signature against raw body instead of CLIENT_ID signed with CLIENT_SECRET.

Fix: Hash CLIENT_ID with CLIENT_SECRET using HMAC SHA-256 and compare using crypto.timingSafeEqual().
CW_ERR_INSUFFICIENT_FUNDS (HTTP 422)

Investment Plan Initialization Blocked

Wallet balance is lower than the asset purchase amount.

Fix: Wallets are the sole funding source. Prompt the user to fund their wallet via bank transfer/card before purchasing.
CW_ERR_WITHDRAWAL_LOCKED (HTTP 422)

Withdrawal Cooldown Window Active

Cowrywise enforces a regulatory 24-hour intent cooling-off security model.

Fix: Inform users of the 24-hour safety review window and listen for the withdrawal.completed webhook.
